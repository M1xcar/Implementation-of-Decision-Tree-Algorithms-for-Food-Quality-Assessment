## 📌 Описание проекта
В рамках данной работы реализован алгоритм решающего дерева (`DecisionTreeClassifier`) для многоклассовой классификации качества красного вина по его физико-химическим характеристикам (на основе датасета **WineQT**). 

### Основные этапы и результаты:
* **Предобработка данных:** Анализ пропусков, удаление дубликатов и неинформативного идентификатора (`Id`).
* **Оптимизация модели:** Подбор оптимальной глубины дерева (`max_depth`) по метрике Accuracy.
* **Метрики качества:** Достигнута точность (`Accuracy`) ~62.88%, рассчитаны Precision, Recall и F1-score.
* **Интерпретируемость:** Построена матрица ошибок (Confusion Matrix), выполнен анализ важности признаков (`alcohol`, `total sulfur dioxide`, `volatile acidity`) и визуализирована структура решающего дерева.
